### 列一些不太直观的操作，其他参考 上述视频 和 rv-desktop

1. 侧边操作栏按视频唤出操作菜单，左侧侧边栏

2. 配置点击此按钮可快速扫描局域网可用的 rv-backend（初始也会自动扫）

![scan]({{URL_IMG}}/file/rv/1781338593263_scan_ip.png)

3. 自动下滑进行中可点击悬浮球停止，自动翻页则点击页数按钮停止

![scan]({{URL_IMG}}/file/rv/auto_roll.png)

4. 滚动模式悬浮球左滑右滑能配合设置的幅度条大幅跳跃

5. 侧边栏三击下方动图，可进行设置初始化（例如还原悬浮球坐标等，与书本离线缓存无关）
