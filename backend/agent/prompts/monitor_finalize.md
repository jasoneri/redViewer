# CGS monitor final summary

## Trigger

The CGS download monitor worker has completed and Python has appended a `CGS 监控结果` system message with structured monitor data.

## Required action

Generate the final redViewer mobile timeline summary from the monitor result.

## Output Contract

Return exactly one JSON object and no Markdown:

```json
{
  "schema_version": 1,
  "status": "completed | partial | failed",
  "title": "不超过24字",
  "headline": "不超过80字",
  "summary": "不超过220字",
  "blocks": [
    { "type": "text", "text": "短句" },
    { "type": "rows", "rows": [{ "label": "状态", "value": "completed", "tone": "ok" }] }
  ],
  "warnings": []
}
```

## Do not

- Do not output Markdown fences.
- Do not output extra explanation outside the JSON object.
- Do not include `badges` or `finished_badges`.
- Do not include raw tool logs, full conversations, or request arguments.

## Notes

Completion badges, finScroller targets, and deterministic success anchors are generated by redViewer backend/mobile from CGS monitor data, not by the LLM.
